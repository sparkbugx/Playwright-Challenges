Playwright + TypeScript — command cheat sheet
=============================================

Setup (first run)
-----------------
npm ci
npx playwright install --with-deps


Run
---
npx playwright test                                  # all challenges, all 3 browsers
npx playwright test tests/<name>.spec.ts             # one challenge
npx playwright test tests/<name>.spec.ts --project=chromium
npx playwright test -g "<test title>"                # one test by title
npx playwright test --ui                             # interactive UI mode
npx playwright test --headed                         # watch the browser
npx playwright test --debug                          # Playwright Inspector


Reports
-------
npx playwright show-report


Maintenance
-----------
npx playwright --version
npm install -D @playwright/test@latest
npx playwright install --with-deps                   # after updating Playwright


Environment (optional)
----------------------
# playwright.config.ts already calls dotenv.config()
# .env is gitignored and currently empty — the labs need no secrets
